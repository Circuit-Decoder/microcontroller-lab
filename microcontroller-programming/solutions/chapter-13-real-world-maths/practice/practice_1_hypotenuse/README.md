# practice_1_hypotenuse

**Task:** Hypotenuse: type two sides of a right-angled triangle and show the third side, using sqrt and pow (Pythagoras).

Test with 3 and 4 (answer 5.000) and 5 and 12 (answer 13.000). `askNumber()` waits inside its own loop until # is pressed, which keeps `loop()` short and readable.
