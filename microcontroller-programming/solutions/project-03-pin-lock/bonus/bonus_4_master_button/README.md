# bonus_4_master_button

**Task:** Master button: the light switches on only if the PIN is correct AND Button A (GPIO 15) is held down while you press # — a two-factor lock.

Two-factor: something you **know** (the PIN) and something you **have or do** (the hidden button). Telling the user "Hold A too!" makes testing easy; a real lock would just say "Wrong" so an intruder learns nothing.
