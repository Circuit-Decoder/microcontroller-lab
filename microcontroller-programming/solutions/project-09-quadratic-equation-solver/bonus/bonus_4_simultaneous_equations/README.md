# bonus_4_simultaneous_equations

**Task:** Simultaneous equations: a second mode that solves two linear equations in x and y.

Press A before typing the first number to switch modes. The same typing code collects 3 or 6 numbers; `needed()` says how many. Test: 2x + 3y = 13 and x - y = -1 (type 1, B 1, B 1) gives x = 2, y = 3. If `det` is 0 the two lines never cross (or are the same line).
