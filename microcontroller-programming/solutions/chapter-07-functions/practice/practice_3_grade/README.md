# practice_3_grade

**Task:** Grade: write String grade(int mark) that returns "A+" for 80 and above, "A" for 70–79, and so on. Test it with five marks on the Serial Monitor.

The grade bands are the common Bangladeshi school ones; change them to match your school. The loop in `setup()` is from Chapter 9; five separate `Serial.println(grade(...))` lines do the same job.
