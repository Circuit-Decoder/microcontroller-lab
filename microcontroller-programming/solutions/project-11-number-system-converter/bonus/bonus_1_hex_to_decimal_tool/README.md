# bonus_1_hex_to_decimal_tool

**Task:** Hex to decimal: add tool D. Use 0–9 and the keys A, B, C, D for the hex digits A–D. (How could you type E and F?)

Answer to the question: the keypad has only A-D, so E and F need a "shift". Here Button A works like the Shift key on a computer: hold it and A becomes E, B becomes F. Because D is a hex digit, delete moved to Button A + D. Up to 7 hex digits are allowed, so the answer always fits in an unsigned long.
