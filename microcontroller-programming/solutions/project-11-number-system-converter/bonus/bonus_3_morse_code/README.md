# bonus_3_morse_code

**Task:** Morse code: in the key-codes tool, also show the Morse code of each digit key (0 = -----, 1 = .----, 5 = .....), as in Project 01.

Digit Morse codes follow a pattern: 1-5 start with dots and end with dashes, 6-9 and 0 start with dashes. The letters A-D could be added too (.-, -..., -.-., -..).
