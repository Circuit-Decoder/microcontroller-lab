# practice_1_every_column

**Task:** Every column: extend E5.1 to scan column 2 as well as column 1. (Hint: set column 1 back to INPUT before you set column 2 LOW.) Print both results on one line.

Press 5: `col 1: 1111   col 2: 1011` (row 2, column 2). If you forget to switch column 1 back to INPUT, a key in column 1 also shows up in the column 2 reading.
