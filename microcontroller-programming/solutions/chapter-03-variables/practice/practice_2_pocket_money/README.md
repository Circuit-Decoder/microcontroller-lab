# practice_2_pocket_money

**Task:** Pocket money: make variables for your weekly pocket money (an int) and the price of a snack (a float). Print how many snacks you can buy and how much money is left over.

100 / 15.5 = 6.45..., and storing it in an `int` keeps only the 6. 6 snacks cost 93.00, so 7.00 is left. Try your own numbers.
