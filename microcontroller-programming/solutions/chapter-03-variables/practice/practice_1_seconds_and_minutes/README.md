# practice_1_seconds_and_minutes

**Task:** Seconds and minutes: change E3.1 so it also prints the time in minutes and seconds, like 2 min 5 s. (Hint: / 60 and % 60.)

After 125 seconds it prints `count is 125  =  2 min 5 s`. `/` between two `int`s throws the remainder away; `%` gives exactly that remainder.
