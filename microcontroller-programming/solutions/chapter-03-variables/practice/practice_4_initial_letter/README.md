# practice_4_initial_letter

**Task:** Initial letter: make a char holding the first letter of your name, and print it ten times on one line with Serial.print. For now you'll need ten lines that all look the same. Notice how repetitive that is: Chapter 9 shows a much shorter way.

Prints `RRRRRRRRRR`. Ten identical lines! In Chapter 9 a `for` loop does it in one: `for (int i = 0; i < 10; i++) Serial.print(initial);`. Note the single quotes around a `char`: 'R', not "R".
