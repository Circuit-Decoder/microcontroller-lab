# practice_2_times_table_grid

**Task:** Times table: fill a 10 × 10 table with table[r][c] = (r + 1) * (c + 1) in a nested loop, then print it.

The table is filled first and printed in a separate pair of loops, to practise both steps. The `+ 1` is because rows and columns count from 0 but the table starts at 1 x 1.
