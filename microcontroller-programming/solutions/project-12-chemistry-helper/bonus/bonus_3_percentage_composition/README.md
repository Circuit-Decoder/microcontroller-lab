# bonus_3_percentage_composition

**Task:** Percentage composition: show what percentage of a compound's mass each element gives (in H₂O, hydrogen is 2 ÷ 18 × 100 = 11.1%).

The percentage needs the total first, but the total is only known after adding every part. So there are two loops: the first adds up, the second prints. Check: H2O gives H 11.1% and O 88.9%, which add to 100%. The lines are written more compactly to fit the % on.
