# bonus_1_more_compounds

**Task:** More compounds: add HNO₃ (nitric acid, 63), Ca(OH)₂ (slaked lime, 74) and MgO (40). But there are only 9 number keys! Use # for a second page of compounds.

Ca(OH)2 has one Ca, two O and two H: the bracket multiplies everything inside it. Totals: HNO3 = 63, Ca(OH)2 = 74, MgO = 40 g/mol. On page 2, keys 4-9 do nothing because those compounds do not exist (`c < COMPOUNDS`)..
