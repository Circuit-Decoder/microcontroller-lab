# bonus_2_keep_going

**Task:** Keep going: after an answer, let A–D use the answer as the first number of a new sum (like a real calculator).

Example: 12 A 3 # shows 15.00; now C 2 # shows 30.00. After a division-by-zero error there is no answer to carry, so the next key starts again. The first number is now shown with 2 decimals, because a carried answer such as 10 / 4 = 2.50 can have them.
