# bonus_2_more_elements

**Task:** More elements: add elements 21 to 30 (Scandium to Zinc). How many lines need to change if you used a constant for the size?

Answer to the question: without a constant, five places say "20" or "21" (two array sizes, two titles, the range check, the error message). With `LAST`, only `LAST` and the two lists change. That is why constants are worth it.
