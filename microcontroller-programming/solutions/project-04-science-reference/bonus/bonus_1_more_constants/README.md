# bonus_1_more_constants

**Task:** More constants: add three more constants on keys C, D and * in mode A (key − '0' won't work for them).

`key - '0'` only works for digit keys, because '0' to '9' sit next to each other in the character code table. 'C' minus '0' is 19, not 10, so each extra key is matched by its own `else if`.
