# practice_4_times_to_halve

**Task:** Times to halve: how many times can you halve 1,000,000 (whole-number division) before it reaches 0?

The answer is 20, because 2 to the power 20 is 1,048,576, just above a million. This is also the number of bits needed to write 1,000,000 in binary (Chapter 15).
