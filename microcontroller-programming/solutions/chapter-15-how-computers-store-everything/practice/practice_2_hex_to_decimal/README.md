# practice_2_hex_to_decimal

**Task:** Hex to decimal: write hexToDecimal("7EA"), like binaryToDecimal() but multiplying by 16. (Hint: a letter's value is c - 'A' + 10.)

7EA = 7 x 256 + 14 x 16 + 10 = 2026. Each new digit multiplies what you already have by 16 before adding, exactly like `binaryToDecimal()` does with 2.
