# bonus_4_remove_a_value

**Task:** Remove a value: in the sorted-list stage, let the person remove a value by its position, then recalculate.

Removing from an array means shifting everything after it one place left and reducing `count`. Removing keeps the order, so there is no need to sort again; the results screen recalculates from the array every time it is drawn. Positions count from 1 for people (the first value is 1).
