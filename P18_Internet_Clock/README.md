# Project 18: Internet Clock

**Exact Bangladesh time from the internet.**  
Book: *Microcontroller Lab* by Circuit Decoder — Tier 4 — Wireless & connected

## Files

- [`P18_Internet_Clock.ino`](P18_Internet_Clock.ino)

## How to open it

1. Easiest: download the whole repository (green **Code** button → **Download ZIP**) and unzip it.
2. Double-click `P18_Internet_Clock.ino`. It opens in the Arduino IDE.
3. Or copy the code: open the `.ino` file above and click the **Copy raw file** button (top right of the code).

## Libraries needed

- Adafruit GFX Library
- Adafruit SSD1306
- Keypad (by Mark Stanley and Alexander Brevig)

Board: **ESP32 Dev Module**, with *esp32 by Espressif Systems* version **3.x**.

## Before you upload

Before uploading, type your Wi-Fi name and password between the quote marks in `WIFI_NAME` and `WIFI_PASSWORD`. The ESP32 only works with 2.4 GHz Wi-Fi.
