# Challenge Yourself — Solutions

Every project in *Microcontroller Lab* ends with **Challenge Yourself** tasks. Here are worked answers for all of them.

**Try first, then look.** You learn the most when you get stuck, think, and try again. Open a solution only after you have really tried — or to check your own answer. Your way may be different and still be right.

## How to use a solution

1. Open the project folder below, then the challenge folder (for example `C2_Star_Clears`).
2. Download the `.ino` file (and any `.h` tab in the same folder). The easiest way is **Code → Download ZIP** on the main page.
3. Open the `.ino` in Arduino IDE. Tabs like `MultiTap.h` must sit in the same folder.
4. Look for lines marked `// CHALLENGE` — those are the new or changed parts.
5. For Wi-Fi and Telegram projects, put in your own Wi-Fi name, password and bot details first. Never share them.

Every solution here has been compiled for the ESP32 (Arduino core 3.0.7) with the same libraries as the book.
