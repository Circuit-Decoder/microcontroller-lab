# Project 2: Science Reference — Part B

**Type an atomic number, see the element.**  
Book: *Microcontroller Lab* by Circuit Decoder — Tier 1 — First steps

## Files

- [`P02_Science_Reference_PartB.ino`](P02_Science_Reference_PartB.ino)

## How to open it

1. Easiest: download the whole repository (green **Code** button → **Download ZIP**) and unzip it.
2. Double-click `P02_Science_Reference_PartB.ino`. It opens in the Arduino IDE.
3. Or copy the code: open the `.ino` file above and click the **Copy raw file** button (top right of the code).

## Libraries needed

- Adafruit GFX Library
- Adafruit SSD1306
- Keypad (by Mark Stanley and Alexander Brevig)

Board: **ESP32 Dev Module**, with *esp32 by Espressif Systems* version **3.x**.
